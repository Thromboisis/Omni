# OmniLaunch - Zero-Cloud Desktop Game Launcher & Store Aggregator

OmniLaunch is built to run as a **native desktop application** (not just a website), giving it direct operating system access to discover, configure, and launch local standalone executables (`.exe`, `.app`, Linux binaries) alongside games from Steam, Epic Games, GOG, and more.

---

## 🚀 Building Desktop Installers via Git (GitHub Actions)

This repository includes a GitHub Actions CI/CD workflow (`.github/workflows/desktop-build.yml`). 

### When Does It Build?
- **Version Change in `manifest.json`:** Pushing ordinary commits to `main` (features, bugfixes, game database edits) will **never** trigger a build. This prevents wasting build time and CI minutes.
- **Trigger a Release Build:** To release a new installer version, simply change the `"version"` field in `manifest.json` (started at `"0.1"`, e.g., bump to `"0.2"`, `"0.3"`, `"1.0"`) and push your commit to GitHub:
  ```json
  // manifest.json
  {
    "version": "0.1",
    "name": "OmniLaunch: Local Game Manager & Deals Aggregator",
    ...
  }
  ```
  The workflow detects that `"version"` changed compared to the previous commit, builds the installers across **Windows**, **macOS**, and **Linux**, and automatically publishes a **GitHub Release** tagged `v0.1` (or `v0.2`) with the installer binaries attached!
- **Manual Trigger:** You can also trigger a build on demand anytime by going to the **Actions** tab in your GitHub repository, selecting **Build & Release Desktop App**, and clicking **"Run workflow"**.

### Output Installers Generated by Git:
- `OmniLaunch Setup 0.1.0.exe` (Windows NSIS setup installer)
- `OmniLaunch-0.1.0.dmg` (macOS Disk Image)
- `OmniLaunch-0.1.0.AppImage` & `.deb` (Linux)

## 💻 Building Locally on Your Desktop

If you have Node.js installed locally, you can build native installers in one command:

### Windows (.exe Setup installer)
```bash
npm install
npm run package:win
```
*Installer output:* `release/OmniLaunch Setup 1.0.0.exe`

### macOS (.dmg Disk Image)
```bash
npm install
npm run package:mac
```
*Package output:* `release/OmniLaunch-1.0.0.dmg`

### Linux (.AppImage & .deb)
```bash
npm install
npm run package:linux
```
*Package output:* `release/OmniLaunch-1.0.0.AppImage`

### Run Instantly in Native Desktop Window (without installing)
```bash
npm install
npm run desktop:start
```

## 🎮 Why Standalone Games Require a Native Desktop Install

A standard web browser is sandboxed for security and cannot launch local executables (`C:\Games\Doom\game.exe`) on your hard drive. 
When packaged as an Electron desktop app:
- OmniLaunch runs natively on your OS.
- It uses native OS system calls (`child_process.spawn`) to launch executables, custom launch flags, and working directories.
- It provides native file explorer dialogs to pick games and scan custom game library folders.
- All game data, tags, and profiles are saved locally on your computer with zero cloud telemetry.
